💻 DSA Algorithms in C

🚀 A collection of Data Structures and Algorithms (DSA) programs implemented in C to improve programming fundamentals, logical thinking, and problem-solving skills.

📌 About This Repository

This repository contains beginner-friendly C programs covering essential DSA concepts. Each program focuses on understanding a particular operation or algorithm through practical implementation.

🎯 The goal is to build a strong foundation in Data Structures and Algorithms through consistent coding practice.

📚 Topics Covered

🔹 1. Arrays

- Find Largest and Smallest Element
- Calculate Sum and Average
- Insert and Delete Elements
- Reverse an Array
- Merge Two Sorted Arrays
- Linear Search
- Binary Search
- Bubble Sort
- Selection Sort
- Insertion Sort

🔹 2. Matrices

- Matrix Addition
- Matrix Transpose
- Matrix Multiplication

🔹 3. Stack

- Push and Pop Operations
- Peek Operation
- Display Stack Elements
- Parentheses Matching
- Infix to Postfix Conversion

🔹 4. Queue

- Queue Operations
- Circular Queue
- Deque Operations
- Priority Queue

🔹 5. Linked List

- Singly Linked List
- Reverse Linked List

🛠️ Technologies Used

- 💻 Programming Language: C
- 📝 Code Editor: Visual Studio Code
- ⚙️ Compiler: GCC

▶️ How to Run the Programs

Step 1: Clone this repository.

git clone https://github.com/gadediksha/DSA-Algorithms-in-C.git

Step 2: Open the project folder.

Step 3: Compile any C program.

gcc filename.c -o output

Step 4: Run the program.

./output

Note: On Windows, use "output.exe" to run the compiled program.
